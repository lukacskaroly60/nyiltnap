# Széchenyi 3D Műhely – nyílt napi bemutató

Kivetíthető weboldal a Székesfehérvári SZC Széchenyi István Műszaki Technikum nyílt napjára (2026. november 11.).
Egy kb. 10 perces előadáshoz készült a 3D szakkörről, az Erasmus+ török partnerségről és az aktuális országos versenyekről.

## Használat

Nyisd meg az `index.html` fájlt böngészőben (internet nélkül is működik, csak a betűtípusok egyszerűbbek).

| Billentyű | Funkció |
|---|---|
| → / ↓ / Szóköz / PageDown | következő dia (az első lapozás elindítja a 10 perces időzítőt) |
| ← / ↑ / PageUp | előző dia |
| F | teljes képernyő |
| N | előadói jegyzetek (időbeosztással) |
| T / R | időzítő indítása, megállítása / nullázása |

## Diák

1. Címlap
2. A 3D szakkör (heti 1 alkalom, 5–15 fő, 3D tervezés, nyomtatás, lézergravírozás, Arduino)
3. A műhelyből: képek
4. Innováció és elismerés (3D nyomtatott Gróf Széchenyi-díj szobrok, OTIO)
5. Erasmus+ „Discover the Green Life with Robots” (Isztambul, 2024 / Székesfehérvár, 2025)
6. Országos 3D Hídépítő Verseny (2026. november 20., BGSZC Mechatronikai Technikum), fotókkal a 2024-es versenyről
7. HARMAN Hackathon (2026. november 13–14., Székesfehérvár)
8. Plakátok: HARMAN Hackathon (hivatalos) és a hídverseny felhívása plakát formában
9. Zárás

A képek az `img/` mappában vannak, kivetítéshez 1600 px-re kicsinyítve.
